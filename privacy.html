Privacy Policy — nekotuki uploader

Last updated: October 17, 2026

Who uses this app

nekotuki uploader is a personal tool. It is used only by the owner of the nekotuki YouTube channels to manage those channels. It is not offered to the public.

What data the app accesses

With the owner's permission through Google sign-in, the app uses the YouTube Data API and YouTube Analytics API to: upload videos, edit video titles, descriptions, thumbnails and playlists, set publishing schedules, reply to comments, and read channel statistics — only for the owner's own channels.

How the data is stored

Sign-in tokens and data are stored only on the owner's own computer. Nothing is sent to any server other than Google's.

Sharing

No data is sold, shared with, or transferred to third parties.

Removing access

Access can be removed at any time from Google Account → Security → Third-party apps.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent through this site's GitHub repository.

プライバシーポリシー（日本語）

nekotuki uploader は個人用のツールで、ねこつきの YouTube チャンネルの持ち主が、自分のチャンネルを管理するためだけに使います。一般には提供していません。

Google のログインで持ち主が許可した範囲で、YouTube Data API と YouTube Analytics API を使い、自分のチャンネルに対してのみ、動画のアップロード、題名・説明・サムネイル・再生リストの編集、公開の予約、コメントへの返信、統計の読み取りを行います。

ログイン情報やデータは持ち主のパソコンにだけ保存し、Google 以外のサーバーには送りません。第三者への販売・共有・提供は行いません。アクセスの許可は、Google アカウントの「サードパーティ製のアプリ」からいつでも取り消せます。
